# Mohaa

تطبيق ويب وواجهة API مكتوبان بـ **FastAPI** لإدارة تحليل روابط فيديو YouTube وتنزيلها، مع حسابات مستخدمين ومفاتيح API وسجل للمهام. اسم المستودع على GitHub بعد إعادة تسميته هو `youtube-video-downloader`.

> هذه الوثيقة مبنية على قراءة ساكنة للملفات. لم تُشغّل الشيفرة أو الاختبارات، ولم يُتحقق عمليًا من الإعداد أو التنزيل أو التكاملات.

## ما يظهر في المصدر

يتضمن الملف `yt_downloader_designed.py` شيفرة لواجهات صفحات وحسابات تشمل التسجيل وتسجيل الدخول والتحقق من البريد واستعادة كلمة المرور وتدفق Google OAuth، إضافة إلى لوحة المستخدم وسجل التنزيلات وإدارة مفاتيح API. كما يحتوي مسارات API لتحليل رابط، وإنشاء تنزيل ومتابعة المهمة والتقدم، واسترجاع سجل المستخدم وحذفه، وقراءة الاستخدام وإدارة مفاتيح API، إلى جانب مساري فحص الصحة والجاهزية.

يستخدم مسار التنزيل `yt-dlp`، ويحتوي المصدر أيضًا على تكامل باسم VidsSave وخيار رجوع إلى `yt-dlp`. وجود هذه الشيفرة لا يثبت توافر الخدمات الخارجية أو نجاح أي عملية تنزيل.

## المتطلبات والملفات

الملفات الموجودة في المستودع:

- `yt_downloader_designed.py` — التطبيق في ملف Python واحد.
- `requirements.txt` — قائمة الاعتماديات.
- `app.db` — قاعدة بيانات SQLite متتبعة في المستودع.

تتضمن قائمة الاعتماديات: `fastapi` و`uvicorn[standard]` و`yt-dlp` و`httpx` و`SQLAlchemy` و`itsdangerous` و`python-dotenv` و`bcrypt` و`python-multipart`. يلزم مفسر Python لتشغيل الملف؛ لا يحدد المستودع إصدار Python موصى به، كما أن الاعتماديات غير مثبتة بإصدارات محددة.

## إعداد وتشغيل مبدئيان

الخطوات أدناه مستنتجة من وجود `requirements.txt` ومن نقطة الدخول في المصدر، وهي **غير مجرّبة**:

1. ثبّت إصدار Python مناسبًا للميزات والاعتماديات المستخدمة.
2. من مجلد المشروع، ثبّت الاعتماديات:

   ```bash
   pip install -r requirements.txt
   ```

3. راجع إعدادات التطبيق في المصدر وجهّز إعدادات البيئة اللازمة قبل التشغيل. لا يحتوي المستودع على ملف إعداد نموذجي يوضح القيم المطلوبة أو قيم افتراضية آمنة.
4. نقطة الدخول الظاهرة في الملف تشغّل Uvicorn عند تشغيل الملف مباشرة:

   ```bash
   python yt_downloader_designed.py
   ```

لم يُجرّب التثبيت أو التشغيل. لا تمثل هذه الخطوات تأكيدًا بأن الإعدادات أو قاعدة البيانات أو خدمات البريد وOAuth والتنزيل جاهزة للعمل. لا يُنصح بتعريض التطبيق للإنترنت قبل مراجعة الإعدادات والبيانات وتأمينه.

## أسماء متغيرات الإعداد التي يستخدمها المصدر

الأسماء أدناه فقط؛ لا يورد هذا الدليل أي قيمة لها. يلزم مراجعة المصدر لمعرفة أيها مطلوب أو اختياري وما الصيغ المناسبة لها:

- التطبيق والاتصال والتخزين: `APP_NAME`, `HOST`, `PORT`, `DATABASE_URL`, `PUBLIC_BASE_URL`, `SECRET_KEY`, `SECURE_COOKIES`, `MAX_FILE_SIZE`, `DOWNLOAD_TIMEOUT`, `FILE_EXPIRATION`, `RATE_LIMIT`, `ADMIN_EMAIL`.
- Google OAuth: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`.
- البريد: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM_EMAIL`, `SMTP_FROM_NAME`.
- تكامل VidsSave: `VIDSSAVE_AUTH`, `VIDSSAVE_DOMAIN`.

لا تضع أسرارًا مباشرة في الشيفرة أو المستودع أو السجلات. خزّنها في إعدادات بيئة آمنة، ودوّر أي بيانات اعتماد سبق نشرها. أسماء المتغيرات وحدها لا تكفي لإثبات أن جميع التكاملات مُهيّأة أو تعمل.

## واجهات API الظاهرة

المسارات التالية موجودة في المصدر؛ لم تُختبر، وقد تتطلب مصادقة أو إعدادًا إضافيًا:

- `POST /api/v1/analyze` — تحليل رابط.
- `POST /api/v1/download` — إنشاء مهمة تنزيل.
- `GET /api/v1/tasks/{task_id}` و`GET /api/v1/tasks/{task_id}/progress` — حالة المهمة وتقدمها.
- `GET /api/v1/download-file/{task_id}` — الوصول إلى ملف التنزيل.
- `GET /api/v1/history` و`DELETE /api/v1/history/{history_id}` — سجل المستخدم.
- `GET /api/v1/me` و`GET /api/v1/usage` — معلومات الحساب والاستخدام.
- `GET /api/v1/api-keys` و`POST /api/v1/api-keys` و`DELETE /api/v1/api-keys/{key_id}` — إدارة مفاتيح API.
- `GET /health` و`GET /ready` — فحوص الصحة والجاهزية.

للتفاصيل الدقيقة عن الطلبات والاستجابات والمصادقة ورموز الأخطاء، راجع تعريفات المسارات في `yt_downloader_designed.py`؛ لا يوجد في الملفات المفحوصة توثيق مستقل لعقد API.

## تنبيهات أمنية وخصوصية

- يحتوي المستودع على `app.db` متتبعة. مخططها يتضمن جداول لحسابات المستخدمين وتجزئات كلمات المرور وحسابات OAuth ورموزها ومفاتيح API وسجلات التنزيل والاستخدام. تعامل مع الملف باعتباره بيانات حساسة: لا تشاركه أو تنشره، ولا تستخدم بيانات حقيقية في نسخة عامة؛ راجع الحاجة إلى تتبعه وأزل البيانات الحساسة أو استبدلها قبل أي توزيع.
- قاعدة البيانات والسجلات وملفات التنزيل قد تتضمن معلومات شخصية أو روابط ومحتوى خاصًا. حدّد صلاحيات الوصول، وسياسة الاحتفاظ والحذف، ومكان تخزين الملفات قبل الاستخدام.
- يتعامل التطبيق مع روابط خارجية وينزّل ملفات. قيّد الاستخدام والحجم والمدة، وافحص طريقة التعامل مع المسارات والملفات، ولا تفترض أن التنزيلات معزولة أو آمنة لمجرد وجود حدود إعداد.
- راجع إعدادات الجلسات وCSRF وOAuth والبريد ومفاتيح API ومعدلات الطلبات قبل النشر. لا توجد في المستودع وثائق أو نتائج اختبار تثبت ملاءمة إعداداته للإنتاج.
- استخدم التنزيل فقط عندما تملك الحق أو الإذن اللازم، والتزم بشروط YouTube والقوانين المحلية وحقوق أصحاب المحتوى.
